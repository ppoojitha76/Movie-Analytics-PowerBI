# 🎬 Movie Review Analytics Dashboard | Power BI

## 📊 Project Overview

This project analyzes movie data to understand movie performance, revenue, budget, ratings, genres, and profitability.

I built an interactive Power BI dashboard to transform movie data into meaningful insights and support data driven decision making.

## 🎯 Business Questions

This dashboard helps answer:

- How does movie revenue change over the years?
- How does budget compare with revenue?
- Which genres have the most movies?
- How do movie ratings change over time?
- How are ratings distributed?
- Which movies generate the highest profit?
- Which genres have better ratings?
- What is the overall profit margin?

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Total Movies | 45K |
| Average Rating | 3.54 |
| Total Revenue | 509bn |
| Average Runtime | 94 min |
| Total Budget | 192bn |
| Profit Margin | 62.31% |
| Average Revenue per Movie | 11.21M |

## 🔎 Key Insights

- Drama has the highest number of movies, with approximately 12K movies.
- Comedy follows with approximately 8.8K movies.
- Revenue shows an increasing trend across the years.
- The dashboard identifies the top 10 most profitable movies.
- Avatar appears as the highest profitable movie in the dashboard.
- Foreign movies have the highest average rating at approximately 4.00.
- Movies with ratings between 3 and 4 form the largest rating group.
